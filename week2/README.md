# Week 2: Neural Prediction from Scratch (Forward Propagation)

##  Overview
This assignment focuses on implementing **forward propagation**. Every operation (except for part 1) is constructed twice using pure Python and then using Numpy.

The project uses the same dataset made up from blade angle, balance and breath to predict 3 potential combat movements: opens left, strikes high or feints.

## File Structure

```
week2/
├── part1_single_prediction.py    # Single input, single weight prediction
├── part2_multiple_inputs.py     # Weighted sum (dot product) from multiple inputs
├── part3_multiple_outputs.py    # Elementwise multiplication for multiple outputs
├── part4_multi_in_multi_out.py  # Vector-matrix multiplication for multi-input/output
├── part5_two_layers.py          # Stacked two-layer neural network
├── forward_propagation.ipynb  # Assembled Jupyter notebook deliverable
└── README.md                    # Project documentation & execution guide
```
