# Week 8: Discipline of Forgetting

Show the problem with models that overfitting and stopping too late. To counter these issues we implemented early stopping and dropout across four partrs. THe four parts show some issues with the neural networks and how to add early stopping, dropout, and mini-batching.

## Files

- `part1_memorize.py`: Memorizes on purpose.
- `part2_early_stopping.py`: Adds early stopping .
- `part3_dropout.py`: Forget parts on purpose: add dropout.
- `part4_train_of_formatting.py`: trains with mini-batching all together.
- `forgetting.ipynb`: parts assembled with short explanations.

## Just Run the Notebook

Open the notebook in Jupyter and choose Restart & Run All.
Its code imports the existing part files, so keep them in the same folder.
